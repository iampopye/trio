Why Trio?

Eight reasons
Fig. 01 · YOUR MODEL

Train it. Ship it. Own it.

Six model tiers from trio-nano (1 GB, runs on a Raspberry Pi) to trio-pro (18 GB MoE).

Built-in pretrain · SFT · DPO · Constitutional AI pipeline. Push tuned weights to your HuggingFace org in one command. No middleman.

# fine-tune on your own data
$ trio train --tier medium \
    --data ./my-corpus \
    --push myorg/trio-medium-mine
Fig. 02 · OLLAMA-NATIVE

Speaks every local protocol.

Every trio model ships as a GGUF + Modelfile. Pull them from any Ollama client. Trio also exposes an Ollama-compatible HTTP API on :11434-equivalent so LM Studio, Jan, Continue, OpenCode, BlackBox, OpenInterpreter all just work.

$ ollama run trio-medium
# or via API
$ curl localhost:11434/api/chat \
  -d '{"model":"trio-max",
    "messages":[...]}'

Discord. Slack. WhatsApp. Telegram. Teams. iMessage. SMS. Email. Matrix. Reddit. Instagram. Messenger. LINE. Signal. Google Chat. Plus the CLI and the web UI.

Fig. 04 · LOCAL FIRST

Never pay for tokens you didn't have to.

Smart Router cascades local → free tier → paid. Picks the cheapest provider that meets the quality bar for each query.

Per-request cost shown in the chat footer. Daily and monthly budget caps. You see the bill before it ships.

trio> what is the capital of france?

  Paris.

_(2.1s · trio-medium · local · $0.00)_

The community hub ships 3,876 of them — coding, marketing, security, finance, legal, data, creative. trio search "python" finds yours.

Fig. 07 · CONSTITUTIONAL

You write the rules.

Five-layer runtime guardrails on top: input filtering, jailbreak detection, content safety, rate limiting, output redaction.

Fig. 08 · YOUR DATA. YOUR DISK.

Nothing leaves unless you say so.

Sessions, memory, RAG store, channel keys — all in ~/.trio/, AES-128 encrypted (Fernet), key bound to the machine.

No telemetry. No phone-home. The only network call trio makes is the one you asked for.

  .secret_key  (chmod 600)
  sessions/    (local only)
  memory/      (local only)
  rag/         (local only)
